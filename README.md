# 🥷 Midnight Shadow: Autonomous AI Ninja Platformer

https://muhammadshamoeel.github.io/NinjaGame/

**Midnight Shadow** is a fast-paced, stylized 2D action platformer that blends classic hack-and-slash mechanics with adaptive gameplay modes. The game features a dual-experience system allowing players to either take absolute manual control of a lethal shadow warrior or sit back and observe an autonomous artificial intelligence clear rooms with perfect mechanical timing.

---

## 🎮 Game Features

* **Dual Engine Gameplay**: Seamlessly toggle between manual combat execution and an automated machine agent.
* **Autonomous AI Autoplay**: Features a built-in automated bot that dynamically pathways levels, tracks threats, and calculates combat responses.
* **Dynamic Combo Combat**: Execute seamless combat maneuvers using high-impact slice weapons, crowd control attacks, and vertical positioning.
* **Intelligent Defense Mapping**: Actively absorb incoming ballistic hazards, traps, and explosive projectiles using a precise directional guarding system.
* **Continuous Loop Cycle**: Zero downtime design with an instant, autonomous 2.0-second auto-respawn system keeping you straight in the action.

## 🕹️ Controls & Mechanics


| Action | Keyboard Input | Touch Control | Mechanic Description |
| :--- | :--- | :--- | :--- |
| **⚔️ Slash** | `J` | Tap Slash | High-velocity horizontal blade strikes to slice through grunts. |
| **🛡️ Shield** | `K` | Tap Guard | Deploys a kinetic barrier to block incoming missiles and bombs. |
| **👣 Stomp** | `Space` / `W` | Tap Jump | Drop downwards directly onto enemy heads to crush targets and trigger a double-jump reset. |

## 🤖 Game Modes

### 👤 Warrior Mode
Test your custom reflexes, active timing, and execution. Take manual control of the ninja to navigate dense obstacle fields, map counter-attacks, and maximize your high score.

### 🤖 Autoplay Mode
An experimental sandbox feature where an autonomous AI platforming routine takes control. The agent automatically paths across platforms, avoids drop hazards, shields from incoming projectiles, and slashes enemies down systematically.
